# 🏥 Health Horizon AI

## 📖 Overview
Health Horizon AI is an AI-powered healthcare platform that helps users manage their health through digital healthcare services.

## ✨ Features
- 👨‍⚕️ Doctor Appointment Booking
- 🏥 Hospital Finder
- 🤖 AI Medical Chatbot
- 🥗 Calorie Tracker
- 👤 User Authentication
- 📊 Admin Dashboard

## 🛠 Tech Stack

### Frontend
- React.js
- Vite
- CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Other
- JWT Authentication
- Cloudinary
- REST API

## 🚀 Installation

```bash
git clone https://github.com/vishalnchavan369-creator/Health-Horizon-AI.git
cd Health-Horizon-AI
```

Install dependencies:

```bash
cd backend
npm install

cd ../frontend
npm install

cd ../dashboard
npm install
```

Run the applications:

```bash
# Backend
npm start

# Frontend
npm run dev

# Dashboard
npm run dev
```
